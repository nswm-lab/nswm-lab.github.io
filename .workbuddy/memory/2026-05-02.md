## 重要教训
- **Python 批量修改脚本不能完全替代逐步 Edit**：脚本中变量定义了但未使用（carousel_css），这种 bug 很难通过 div balance 检查发现
- **使用脚本修改后务必验证**：不仅检查 div balance，还要检查实际 CSS 内容是否完整注入
- **HTML 注释完整性**：Jekyll/Kramdown 会输出 HTML 注释中的内容到页面，如果注释标记不完整会导致文本泄漏

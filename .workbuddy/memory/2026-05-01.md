## 本地预览服务器重启流程
- 项目使用 Jekyll 构建 + Python HTTP Server 静态服务
- 修改源文件后需要：`bundle exec jekyll build` 重建 → 重启 Python 服务器
- 重启步骤：`taskkill //F //PID <pid>` → `cd _site && python -m http.server 4000`
- 或直接用 `rebuild-and-serve.bat`（但需先 `set ACC_PRODUCT_CONFIG_V3=` 避免 bundler 报错）
- Bash 中用 `cmd //c "set ACC_PRODUCT_CONFIG_V3= && bundle exec jekyll build"` 可以绕过环境变量问题

## 教训
- 修改前一定要看清用户截图/描述的具体区域，不要改错位置
- 不要随意改 hero 区域间距等用户没提到的地方
- 给容器加 flex 布局要谨慎，可能影响子元素尺寸
